# Sounder

Scopri artisti affini a quelli che ami: swipe a destra se ti piacciono, a sinistra se no. Ascolti con Spotify (serve Premium).

- Sito: https://cseleonid.github.io/Sounder/
- Artisti simili: Last.fm. Schede: Wikipedia. Ascolto e libreria: Spotify.
- Le tue scelte restano nel browser (nessun server).

Sul primo avvio apri **Opzioni** e inserisci il Client ID della tua app Spotify e la chiave Last.fm.
